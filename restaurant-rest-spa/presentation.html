07 / Response contract08 / 17

HTTP contract

API response contract.

Success
HTTP 200
{"ok":true,"data":{"status":"available"}}

Creates explicitly use HTTP 201. Handler builders call res.json; lists and records sit inside data.

Business error
HTTP 200
{"ok":false,"error":{"code":"VALIDATION_FAILED","message":"<message>","fields":{"name":"<field message>"}}}

Missing records use NOT_FOUND; invalid fields use VALIDATION_FAILED.

Technical errors

Unknown API paths return 404; system failures return 500. Bodies omit ok.

Client handling

api() returns data or throws ApiError with code and fields.

Transport failure

A rejected fetch has no HTTP response; status is 0.

The public list is GET /api/menu; dish detail uses UUID :id. Admin CRUD uses /api/admin/dishes/:id. Business errors use HTTP 200; technical errors use HTTP status codes.

Evidence: admin-handlers.js, public-handlers.js, error-handler.js, lib/errors.js, client/src/api.js. Table ellipses and angle-bracket labels denote variable data or messages.

16 / Browser boundary17 / 17

CORS and deployment

CORS origin policy and deployment.

Configured policy
CLIENT_ORIGIN
default: http://localhost:5173
comma-separated exact matches

methods: GET, POST, PATCH, DELETE, OPTIONS
allowed headers: Content-Type
credentials: not enabled
Allowed origin receives Access-Control-Allow-Origin: http://localhost:5173 and Vary: Origin. Preflight returns 204 with allowed methods and headers.
Disallowed origin

Express continues without CORS headers. Simple requests may execute, but browser code cannot read the response. Failed preflight blocks the follow-up request.

Purpose

CORS controls browser access to cross-origin responses. It is not authentication; no admin auth middleware is registered.

Development

Vite :5173 proxies /api to Express :3000.

Production

Express serves the client build and SPA fallback when present. Separate origins must match CLIENT_ORIGIN.

Evidence: server/src/app.js origin callback; installed CORS defaults; client/vite.config.js; optional static fallback in app.js.
